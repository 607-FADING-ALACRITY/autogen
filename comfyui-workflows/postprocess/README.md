# Post-processing: portrait blur → LUT → lens → sharpen → grain → JPEG

A finishing pass for any image, including the output of `../fineporn-faceswap`:

```
image ──► portrait blur (optional) ──► LUT grade ──► lens ──► sharpen ──► film grain ──► JPEG
             ▲            ▲
   subject mask (BiRefNet)  depth (Depth Anything 3)     ← both skipped entirely when blur is off
```

The order is deliberate:
- Blur comes before the grade, so bokeh takes the grade's colors like a real lens would.
- Lens effects come after the grade and before sharpening and grain, the same order light takes: lens, then sensor.
- Sharpening comes before grain, so the grain itself isn't sharpened.
- Grain is last, so it sits evenly over blurred and sharp areas alike. A blurred background with no grain is the most common giveaway of a fake portrait mode.

2. **Node pack.** Copy `comfyui-postfx/` into `ComfyUI/custom_nodes/` and restart. No pip installs; it only uses torch, numpy and Pillow, which ComfyUI already has.

## Nodes

### PostFX · Portrait Blur

A phone-style portrait mode. The subject stays sharp, and background blur grows with distance from the subject.

- **Depth-graded lens blur.** The blur is a disc shape, like a real lens, applied in linear light at up to 16 radii and blended per pixel by depth. The subject mask sets the focus plane (median depth of the subject) and keeps the subject pixel-perfect.
- **No halo.** Each blur layer is a weighted average that excludes in-focus pixels, so the subject never glows into the background.
- **Highlight bloom.** Only small, near-white highlights (lamps, sun through leaves) bloom into bokeh balls. Sky and other large bright areas keep their exposure.

| Setting | Default | Effect |
|---|---|---|
| `enabled` | true | When off, the image passes through untouched. Depth and subject models don't run. |
| `blur_strength` | 1.5 | Maximum blur radius as % of the long side. Phone portrait mode is about 1–2. |
| `falloff` | 0.3 | How far behind the subject (in normalized depth) the blur reaches maximum. Lower values give a softer background sooner. |
| `highlight_bloom` | 0.35 | Strength of the bokeh balls on point lights. |
| `edge_softness` | 1.5 | Feather on the subject mask edge, in pixels. |

Both inputs are optional, but at least one must be connected:
- **Mask only:** a two-layer blur. Faster, and fine for studio-style backdrops.
- **Depth only:** focus falls on the nearest 10% of the scene.

### PostFX · Apply LUT

Applies Adobe/Resolve `.cube` LUTs, 3D (trilinear) or 1D, and honors `DOMAIN_MIN`/`DOMAIN_MAX`. `strength` blends between the original and the graded image.
- **Where LUTs go:** drop `.cube` files into `ComfyUI/models/luts/`. The bundled starters appear automatically.
- **Which LUTs:** use **display-referred** (Rec.709/sRGB in → out) LUTs. Camera LOG-to-Rec.709 conversion LUTs expect LOG footage and will look wrong.
- **Making your own:**
  - Photoshop: *File → Export → Color Lookup Tables* exports a `.cube` from adjustment layers.
  - DaVinci Resolve: right-click a node → *Generate LUT*.
  - Lightroom can't export LUTs directly.
- **Starters** (generated by `tools/make_luts.py`, free to use):
  - `warm_film`: soft S-curve, lifted blacks, warm highlights, slightly cool shadows, −8% saturation.
  - `bright_clean`: +⅓ stop with highlight roll-off, low contrast, faint warmth.

### PostFX · Lens

The optical fingerprints a phone lens leaves and AI renders lack.

| Setting | Default | Effect |
|---|---|---|
| `chromatic_aberration` | 1.0 | Red/cyan fringe width at the corners, in pixels per 1000 px of image diagonal. 0.5–1.5 reads as a phone lens. Only visible on sharp edges. |
| `vignette` | 0.25 | Corner darkening in linear light. 0.25 is about a third of a stop; 1.0 is about 1.3 stops. |

Set both to 0 to turn it off.

### PostFX · Sharpen

An unsharp mask applied to luminance only, so edges get no color fringes.

| Setting | Default | Effect |
|---|---|---|
| `amount` | 0.5 in the workflow (node default 0.6) | Sharpening strength. |
| `radius` | 1.0 | Gaussian sigma in pixels. |
| `threshold` | 0.02 | Detail below this contrast is left alone. Raise it if skin gets crunchy. |

### PostFX · Film Grain

Gaussian grain, clumped to `size` pixels.
- **Tonal response:** strongest in midtones and about a quarter as strong in deep shadows and highlights, like real sensor or film noise.
- **Color:** `color` mixes monochrome grain with chroma (sensor-like) noise.
- **Seed:** randomizes on every run, so a batch doesn't share one grain pattern.

| `amount` | Look |
|---|---|
| 0.2 | Subtle |
| 0.3 | Phone camera (default) |
| 0.5+ | Film |

### PostFX · Save JPEG

| Setting | Default | Notes |
|---|---|---|
| `quality` | 92 | 90–95 is visually lossless. |
| `chroma_subsampling` | 4:4:4 | Keeps red and skin-tone edges crisp. Use 4:2:0 for smaller files. |
| `progressive` | true | |
| `ai_disclosure` | AI-generated | Writes the IPTC `DigitalSourceType` tag. |

Metadata policy:
- **Always embedded:** an sRGB ICC profile, so colors render the same everywhere.
- **Never embedded:** the ComfyUI prompt or workflow. Core *Save Image* writes both into every PNG, which can leak creator names, prompt details and file paths to anyone who downloads the file.
- **AI disclosure tag:** the `DigitalSourceType` tag is what Meta (Instagram and Facebook "AI info" labels) and C2PA-aware tools read. Labeling photorealistic AI content is required by Meta's policy, the platforms' rules and the Krea 2 license (§4.3).

| `ai_disclosure` value | Writes |
|---|---|
| AI-generated | `trainedAlgorithmicMedia`. Use for FinePorn output and face swaps onto generated bodies. |
| Real photo edited with AI | `compositeWithTrainedAlgorithmicMedia`. Use for a real photo with AI edits, e.g. a face swap onto a real shoot. |
| No AI used | No tag. Only for real photos run through this pipeline with portrait blur off. |

## Automating (API format)

Upload the image with `POST /upload/image`, then post `{"prompt": <postprocess_api.json>}` to `/prompt` with these fields patched:

| Node id | Inputs |
|---|---|
| `1` | `image` |
| `15` | `enabled`, `blur_strength`, `falloff` |
| `20` | `lut_name`, `strength` |
| `21` | `chromatic_aberration`, `vignette` |
| `30` | `amount`, `threshold` |
| `31` | `amount`, `seed` (set a new seed per image) |
| `40` | `filename_prefix`, `quality`, `ai_disclosure` |

## What was tested

Everything here runs on CPU, so unlike the face-swap stages this pipeline was **executed end to end** with the real BiRefNet and Depth Anything 3 weights:
- **Test images:** a composite portrait (a NASA public-domain photo over a street scene) and a backlit street shot from the Depth Anything V2 demo set (Apache-2.0).
- **Visual check:** the subject stays sharp, the background blur grades with depth, there's no halo, and the sky keeps its color.
- **JPEG check:** the file carries the AI tag and ICC profile, has no EXIF, and contains no workflow or prompt text.
- **Timing:** about 50 s per image on a 4-core CPU with the blur on, almost all of it BiRefNet and Depth Anything. With the blur off it takes 0.5 s, confirming both models are skipped. A GPU is far faster; it wasn't measured here.
- **Unit tests:** `tools/test_postfx.py` has 23 tests covering:
  - identity, channel order, 1D and domain handling for LUTs
  - lens: identity at zero, vignette falloff, fringe direction and growth toward corners
  - sharpen threshold behavior
  - grain calibration and determinism
  - blur: subject preservation, no halo, depth-driven focus, bloom that spares sky and skyline, lazy skipping
  - JPEG metadata

  Run them with: `COMFYUI_PATH=/path/to/ComfyUI python -m pytest tools/test_postfx.py`
